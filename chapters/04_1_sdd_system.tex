\section{Thiết kế hệ thống (System Design)}
\label{sec:sdd_system_design}

\subsection{Kiến trúc hệ thống (Architecture Diagram)}
\label{subsec:sdd_architecture}

Hệ thống Manga Creation Workflow and Publishing Management System được thiết kế theo mô hình kiến trúc ba lớp (Three-Tier Architecture), bao gồm:
\begin{itemize}
    \item \textbf{Lớp giao diện người dùng (Presentation Layer):} Cung cấp giao diện tương tác cho các đối tượng sử dụng như Admin, Mangaka, Assistant, Tantou Editor và Editorial Board.
    \item \textbf{Lớp xử lý nghiệp vụ (Business Logic Layer):} Thực hiện các chức năng xử lý nghiệp vụ của hệ thống như quản lý Series, Chapter, Task, Submission, Review, Ranking và Notification.
    \item \textbf{Lớp dữ liệu (Data Layer):} Quản lý việc lưu trữ, truy xuất và cập nhật dữ liệu trong cơ sở dữ liệu.
\end{itemize}
Mô hình kiến trúc ba lớp giúp hệ thống dễ bảo trì, dễ mở rộng và nâng cao khả năng tái sử dụng các thành phần chức năng.

\subsection{Kiến trúc triển khai (Deployment Diagram)}
\label{subsec:sdd_deployment}

Hệ thống được triển khai theo mô hình Client -- Server.

Trong mô hình này, người dùng truy cập hệ thống thông qua trình duyệt Web trên thiết bị cá nhân. Các yêu cầu từ người dùng được gửi đến máy chủ ứng dụng để xử lý và trao đổi dữ liệu với cơ sở dữ liệu.

Kiến trúc triển khai bao gồm các thành phần chính:
\begin{itemize}
    \item \textbf{Client:} Là thiết bị của người dùng sử dụng trình duyệt Web để truy cập hệ thống.
    \item \textbf{Application Server:} Tiếp nhận và xử lý các yêu cầu từ Client, thực hiện các nghiệp vụ của hệ thống và trao đổi dữ liệu với cơ sở dữ liệu.
    \item \textbf{Database Server:} Lưu trữ toàn bộ dữ liệu của hệ thống bao gồm dữ liệu người dùng, Series, Chapter, Page, Task, Submission, Review, Ranking và Notification.
\end{itemize}
Kiến trúc Client -- Server giúp tập trung quản lý dữ liệu, tăng khả năng mở rộng hệ thống và hỗ trợ nhiều người dùng truy cập đồng thời.

\subsection{Công nghệ sử dụng (Technology Stack)}
\label{subsec:sdd_tech_stack}

Hệ thống "Manga Creation Workflow and Publishing Management System" được xây dựng trên một ngăn xếp công nghệ đồng bộ và thực tiễn, tối ưu hóa cho mô hình kiến trúc 3 lớp (Three-Tier Architecture). Chi tiết công nghệ tại các lớp như sau:

\begin{enumerate}
    \item \textbf{Lớp giao diện (Presentation Layer):}
    \begin{itemize}
        \item \textbf{HTML5:} Đóng vai trò là ngôn ngữ đánh dấu cấu trúc thông tin hiển thị trên trang web. Đảm bảo tuân thủ tiêu chuẩn ngữ nghĩa (Semantic HTML) và khả năng tối ưu hóa tìm kiếm (SEO).
        \item \textbf{CSS3 \& Bootstrap 5:} Bootstrap 5 được sử dụng để xây dựng hệ thống giao diện phản hồi nhanh (Responsive UI) thích ứng với nhiều kích thước màn hình khác nhau (Desktop, Tablet, Mobile). CSS3 tùy chỉnh để làm mịn các trải nghiệm thị giác (hiệu ứng hover, chuyển cảnh, bo góc).
        \item \textbf{JavaScript (ES6) \& Fetch API:} Hỗ trợ xử lý các tương tác thời gian thực từ người dùng (như bật/tắt cửa sổ thông báo, cập nhật tiến độ vẽ). Fetch API được dùng để giao tiếp bất đồng bộ (AJAX) với máy chủ để thực hiện lưu trữ hoặc cập nhật dữ liệu mà không cần tải lại toàn bộ trang (ví dụ: gửi nhận xét Review).
    \end{itemize}

    \item \textbf{Lớp xử lý nghiệp vụ (Business Logic Layer):}
    \begin{itemize}
        \item \textbf{PHP 8.x:} Ngôn ngữ lập trình chính được thực thi ở phía máy chủ (Server-side). PHP xử lý các logic nghiệp vụ phức tạp của quy trình manga bao gồm: kiểm soát quyền truy cập của các Actor (Admin, Editor, Mangaka, Assistant), phân công công việc và tính toán điểm xếp hạng (Ranking).
        \item \textbf{Mô hình MVC (Model-View-Controller):} Phân tách mã nguồn thành 3 thành phần chính:
        \begin{itemize}
            \item \textit{Model:} Quản lý logic dữ liệu và thực hiện các câu truy vấn thông qua PDO (PHP Data Objects).
            \item \textit{View:} Nhận dữ liệu từ Controller và trả về mã HTML hiển thị ở trình duyệt.
            \item \textit{Controller:} Tiếp nhận các yêu cầu HTTP (GET/POST), xử lý điều hướng, gọi Model thích hợp để thao tác dữ liệu và chuyển tiếp kết quả đến View.
        \end{itemize}
        \item \textbf{Session \& Cookie Management:} Quản lý phiên làm việc của người dùng nhằm đảm bảo tính bảo mật và duy trì trạng thái đăng nhập sau khi xác thực thành công.
    \end{itemize}

    \item \textbf{Lớp cơ sở dữ liệu (Data Layer):}
    \begin{itemize}
        \item \textbf{MySQL 8.0:} Hệ quản trị cơ sở dữ liệu quan hệ (RDBMS) mạnh mẽ, an toàn và tối ưu cho các luồng dữ liệu liên kết phức tạp. Lưu trữ toàn bộ 14 thực thể cốt lõi của hệ thống, hỗ trợ ràng buộc toàn vẹn dữ liệu (Integrity Constraints) qua hệ thống khóa ngoại chặt chẽ.
        \item \textbf{PDO (PHP Data Objects):} Lớp trừu tượng hóa dữ liệu của PHP, cung cấp các hàm API an toàn để tương tác với cơ sở dữ liệu MySQL, ngăn chặn các cuộc tấn công SQL Injection thông qua Prepared Statements.
    \end{itemize}
\end{enumerate}
